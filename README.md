# Bé Học Toán 🦄

Game làm toán cho bé lớp 1 (Nhã Đan): phép cộng (tổng đến 99), phép trừ (số trừ tối đa 10), so sánh điền dấu > < = (phạm vi 99). Mỗi loại có 10 level (10 → 99), có âm thanh, lời khen, giọng đọc tiếng Việt và lưu điểm.

Chơi online: https://quanvpit.github.io/game-lam-toan/

## Chạy trên máy

```bash
npm install
npm run dev
```

## Cập nhật bản online

```bash
npm run deploy
```

Lệnh này build game và đẩy lên nhánh `gh-pages`; GitHub Pages tự cập nhật sau khoảng 1 phút.

## Chỉnh luật chơi

Xem `src/config.js`: danh sách level, số câu mỗi level, số câu cần đúng để qua, điểm mỗi câu.
